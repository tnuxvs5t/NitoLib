# Nitori / design lab

这是用户在完整归档 V3 后授权的下一代设计展示场。`src-v3/` 仍是现有库；
这里的 `nitori::` 原型独立编译，不是 V3 兼容层，也没有替换正式接口。

实验只改变三个默认假设：位置计划显式持有；图算法使用稠密整数编号；
普通数据结构直接拥有自己的数组。泛型保留在数值、代数和邻接访问这些真实变化点上。

```text
include/     独立 C++23 模块，只依赖标准库
examples/    题型配方，每个都是可执行程序
tests/       固定与随机独立 oracle、深链、成本对照
run.py       严格编译、sanitizer、独立头文件检查与证据输出
DESIGN.md    决策、代价和未迁移能力
```

运行：`python3 design-lab/run.py`。当前实验不遵循 V3 的全局 64 位位置切换：
编号固定 `int`，坐标和值按题选择宽度。这是待评审的设计取舍。
当前模块覆盖范围有限，不应以它们的体积与完整 V3 比较“缩减率”。

展示页与纸面版由本任务的构建脚本从这里的已验证源码生成。
